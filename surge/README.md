# @rbxts/surge

Binary serializers for roblox-ts, generated from a TypeScript type at compile
time. This is the runtime package that the generated code calls.
[`rbxts-transformer-surge`](https://github.com/travddm/surge/tree/master/rbxts-transformer-surge)
generates that code. Neither package is released yet; until the first
release, a project installs a pre-release build of both from the surge
repository, at the same build.

[Getting started](https://github.com/travddm/surge/blob/master/docs/getting-started.md)
registers the transformer and writes a first serializer. The rest of the documentation is in
the [surge repository](https://github.com/travddm/surge), and contributors
start with its
[AGENTS.md](https://github.com/travddm/surge/blob/master/AGENTS.md).
