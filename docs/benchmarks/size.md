# Benchmark results: bytes per value

Generated by `mise run bench:size`; do not edit by hand. Tier 1 of the
harness in [future-work/benchmark-tooling.md](../future-work/benchmark-tooling.md).

`Bytes` is the serialized buffer for one sample value of the shape. `Side`
is the number of values passed outside that buffer (surge's blob array),
which cost bandwidth the buffer does not show. `Round trip` is `inexact`
where the decoded value differs from the input at all: surge stores a
`CFrame` rotation as an axis-angle triple, which is exact only for the 24
axis-aligned rotations.

Only surge has an adapter so far, so there is one column per metric and no
ratio. fbs, serio, Blink, and Zap each add their own columns over these same
fixtures.
